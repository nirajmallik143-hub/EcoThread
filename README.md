## 🚀 Quick Start

### Installation
Deploy the environment via Pip to begin the optimization protocol:
`bash
pip install ecothread
`

### Basic Analysis
Run the primary heuristic engine on any Python file:
`bash
python main.py analyze your_script.py
`

### AI-Powered Refactoring
Trigger the Mallik Group AI Engine to rewrite inefficient code:
`bash
python main.py refactor your_script.py
`

## 🧠 7G Architecture & Design
EcoThread operates on a unique software architecture developed by Niraj Mallik. Unlike standard static analyzers, EcoThread simulates the execution path to identify "Heat Zones" in the code—segments where the CPU cycles are wasted on redundant operations.

1. Compassion in Code: Reducing server load reduces global heat waste.
